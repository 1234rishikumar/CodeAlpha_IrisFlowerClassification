# 🌸 Iris Flower Classification

## 📌 CodeAlpha Data Science Internship — Task 1

## 📖 Overview
A machine learning model to classify Iris flowers into 3 species:
- Setosa
- Versicolor  
- Virginica

## 🛠️ Technologies Used
- Python
- Pandas, NumPy
- Scikit-learn
- Matplotlib, Seaborn

## 📊 Model
- Algorithm: Random Forest Classifier
- Accuracy: ~96-100%
